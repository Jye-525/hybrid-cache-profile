# hybrid-cache-profile
This is the repo for 'Hybrid KV/State Cache Characterization and Layer-Aware Cache Optimization in LLM Inference Serving' project. It aims to study the behavior from the model architecture outward. We will inspect selected Hugging Face implementations, trace the forward path, identify exactly where KV or recurrent state is created and updated, and measure the memory associated with each layer or layer group. The characterization will then guide one practical layer-aware optimization. The goal is not to remove caching from arbitrary layers, but to determine where full historical KV is required and where a bounded, shared, compressed, or recurrent representation is sufficient.
